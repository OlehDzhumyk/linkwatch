# Adding a Web UI Language (i18n Guide)

`linkwatch` serves its Web UI offline with zero runtime frameworks or CDNs. Translations are compile-time strict TypeScript dictionaries (`src/web/ui/src/locale_<code>.ts`) registered in a single list.

Supported languages currently include **English (`en`)** and **Ukrainian (`uk`)**. Note: Russian (`ru`) is intentionally excluded from this project.

## How Fallback Works

- `EN` in [src/web/ui/src/locale_en.ts](../src/web/ui/src/locale_en.ts) defines the canonical key type `MsgKey`.
- Any partial locale falls back cleanly per key to `EN[key]`. Official full locales are typed `Record<MsgKey, string>` so `tsc` catches missing keys at build time.
- Interpolations like `{mode}` or `{loss}` use simple placeholder replacement on plain strings (`textContent` only — never `innerHTML`, complying with strict Content Security Policy).

## Adding a New Language in 3 Steps

1. **Create the dictionary file** `src/web/ui/src/locale_<lang>.ts` (e.g., `locale_pl.ts`):

   ```ts
   import type { MsgKey } from "./locale_en.js";

   export const PL: Record<MsgKey, string> = {
     "nav.live": "Na żywo",
     // ... copy and translate all keys from locale_en.ts
   };
   ```

   You can start incrementally with `Partial<Record<MsgKey, string>>` while translating; missing keys will display English automatically.

2. **Register it in** [src/web/ui/src/i18n.ts](../src/web/ui/src/i18n.ts):

   ```ts
   import { PL } from "./locale_pl.js";

   export const LOCALES: readonly LocaleDef[] = [
     { code: "en", label: "EN", messages: EN },
     { code: "uk", label: "UA", messages: UK },
     { code: "pl", label: "PL", messages: PL },
   ] as const;
   ```

3. **Embed the compiled module in** [src/web/mod.rs](../src/web/mod.rs) (`UI_MODULES`):

   ```rust
   ("locale_pl.js", include_str!("ui/dist/locale_pl.js")),
   ```

4. **Rebuild & verify:**

   ```sh
   npm run check
   npm run build
   ```

   Commit both the new `locale_<lang>.ts` source and its compiled `src/web/ui/dist/locale_<lang>.js` output.
